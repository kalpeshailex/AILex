# Product Roadmap

## V1 — Legal First-Aid MVP
Domains:
Police, Traffic, Railway, Government/RTS, Cyber.

Features:
OTP, voice, text, Live Situation, RAG, citations, risk, incident save/not-save, local evidence references, complaint drafts, escalation and feedback.

## V2 — Document Intelligence
- OCR
- document upload
- document classification
- document extraction
- challan analysis
- police/railway/government/legal notices
- optional secure cloud backup
- advanced evidence
- better multilingual support

## V3 — Broader Platform
Potential:
- BMC
- RTO
- Housing
- Consumer
- Employment
- Advanced Cyber
- Maharashtra-wide coverage
- lawyer network
- human review
- advanced voice
- deadline monitoring
- workflow automation

## Rule
Do not move V2/V3 features into V1 without explicit approval.
